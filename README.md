## ✨ Core Features

*   **Real-time Data:** Fetches current weather using the Open-Meteo API.
*   **Detailed Forecasts:** Includes hourly breakdown and a 7-day daily forecast.
*   **Unit Conversion:** Seamless toggle between Celsius/Fahrenheit, km/h / mph, and mm/in.
*   **City Search:** Instant search for any location worldwide.
*   **Responsive Design:** Optimized layout using CSS Grid and Flexbox for desktop and mobile devices.

## 🛠 Tech Stack

*   **Frontend:** React.js, Vite
*   **Styling:** Custom CSS3 (Variables, Grid, Flexbox)
*   **API Integration:** Open-Meteo API

## 💻 Local Installation

1. Clone the repository:

2.Navigate to the project directory:
cd Weather-app
